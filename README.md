# Python CSV Data Analysis with Pandas

## Overview

This is an introductory Python data analysis exercise developed as part of my computer science coursework at Kean University.

The project demonstrates how to use the Pandas library to load and inspect data stored in a CSV file.

## Technologies Used

- Python
- Pandas
- CSV

## Project Files

- `data_analysis.py` — Python script that reads and displays information from a CSV dataset.
- `sample.csv` — Sample dataset containing course information.

## Features

- Loads CSV data into a Pandas DataFrame.
- Displays dataset information, including column names and data types.
- Displays the first five rows of the dataset.

## How to Run

**1. Clone the repository**

```bash
git clone https://github.com/parisalexa21-debug/CPS3500-python_obi2.git
```

**2. Navigate to the project folder**

```bash
cd CPS3500-python_obi2
```

**3. Install Pandas**


**4. Run the script**

```bash
python data_analysis.py
```

## Dataset

The sample CSV file contains five university courses, including their department codes, course numbers, and course names.
